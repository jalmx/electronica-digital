# Práctica 1 - Generación de compuertas básicas con interruptores

## Objetivo 

Conocer y comprender el funcionamiento básico con interruptores y cómo operan las compuertas lógicas básicas.

## Desarrollo

En esta práctica se implementarán y analizarán circuitos lógicos básicos mediante el uso de interruptores, con el propósito de comprender de manera práctica el funcionamiento de las compuertas lógicas AND y OR.

Para cada configuración se construirá el circuito correspondiente en un protoboard, utilizando interruptores como entradas lógicas y un LED como indicador de la salida. Se realizaron diferentes combinaciones en los estados de los interruptores y se observó el comportamiento del LED en cada caso.

Los resultados obtenidos permitieron relacionar el comportamiento físico de los circuitos con las respectivas tablas de verdad, identificando las condiciones necesarias para que la salida de cada configuración se encuentre encendida o apagada.

Finalmente, se analizarán posibles aplicaciones prácticas de las configuraciones AND y OR, relacionando los conceptos estudiados con situaciones en las que es necesario establecer condiciones lógicas para controlar una salida.
