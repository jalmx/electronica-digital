# Práctica 8 - Mapa de Karnaugh

## Objetivo

Aplicar los conocimientos de reducción con mapa de Karnaugh.

## Materiales

| Cantidad | Nombre                  | Descripción |
| -------- | ----------------------- | ----------- |
| 1        | Multímetro              | Voltímetro  |
